Stage 5 step (e): the runtime's policy cells are R0's own management state (d6, draft on 849f6bdd)

SCOPE (6f's (1)-(4), 2026-09-14)
(1) The host setters that write runtime-level cells become R0's own cells (class 1): Structure data in R0's arena,
    written only on R0's lane.
(2) A setter called from any lane but R0's refuses (INVALID) with the value unchanged. Until (f), R0's lane is the
    host outside any turn (the bootstrap) and R0's own turn through root_turn. Reads stay where they are (a late read
    changes nothing), including drive's reads on the host between turns.
(3) Nothing else moves: drive and host_drain stay (c)/(b); set_now calls from main stay legal until (f), since main
    is R0's lane between turns; runtime_delete is (f).
(4) 6f writes the acceptance first from this design.

SPEC (quoted, Lingvamyxa_spec.txt)
- 19.28.R2.2 (11432-11434): "Its management state is ordinary Structure data, to be implemented in L2, not an
  external C control model."
- 11451-11453: "Each parent Message contains the scheduler for its direct children: its policy and management state
  are ordinary private Structure data."
- 11492-11494 (Mikhail, 2026-09-14): "one arena, one lane, one writer. A Message's scheduler and management state is
  written only on that Message's own lane".
- 19.29.7 (12747): an L2 implementation "keeps management state as Structure data".

MEASURED (d6/stage5-hostpick tree; the inventory is scratchpad stage5e_inventory.md)
- Runtime-level policy cells written by host setters, exactly two groups:
  - rt->clock with rt->clock_test: lmx_msg_set_now (lm1 2204 / lm2 msg_set_now 2286), authority
    lmx_msg_host_is_owner(rt) only (no holding_any check, so a turn on the host thread passes today). Read by
    exec.c lmx_msg_now (401-407): clock_test != 0 -> rt->clock, else the real clock. 16 callers, all from main
    (exec selftest 3, release_17 3, liveness_33 7, orphan_mapped_17 3).
  - rt->orphan_retain: lmx_msg_set_orphan_retain (exec.c 4130), no authority check; default LMX_MSG_ORPHAN_RETAIN
    in runtime_new (lm1 864). Read by lmx_msg_orphan_deadline (lm1 1562), used by the sweep. 2 callers from main
    (release_17 1, orphan_mapped_17 1).
- Not runtime-level, so out of scope: lmx_msg_set_orphan_until (one Message's orphan_until, a test seam; the sweep
  writes the same cell), the live_test setters (per-Message live_seq and live_wait_th, lmx_msg_require_owner),
  lmx_msg_set_graph (per-Message wiring). No runtime liveness deadline cell exists: poll, drive and live_check take
  the threshold as an argument.
- runtime_new calloc's the runtime (clock = 0, clock_test = 0), writes next_addr = 1 (address allocation, not
  policy) and orphan_retain, then creates R0 (1) and the UI lane (2).
- The model: lmx_sched_record.lm2, a profile: runtime unit. The record is an Lmx node with fixed known-typed cells
  allocated in the owner's arena (lmx_*_new_owned on owner\blocks/owner\ranges), rooted by lmx_msg_root_attach, read
  and written through known accessors.

DESIGN
1. R0's policy record, three cells in R0's arena, rooted in R0: clock (unsigned), clock_test (int), orphan_retain
   (unsigned, default LMX_MSG_ORPHAN_RETAIN). Its accessors are known reads and known stores, as lmx_sched_record's.
2. runtime_new creates the record right after R0 (the bootstrap is R0's lane) and fails the runtime on OOM, as it does
   for R0 and the UI lane; rt->clock, rt->clock_test and rt->orphan_retain are deleted from LmxMsgRuntime.
3. lmx_msg_set_now and lmx_msg_set_orphan_retain (lm1 and lm2 mirrored where they live) refuse unless R0's lane
   holds: holding_turn(R0), or the host outside any turn (host_is_owner && holding_any == 0). On refusal nothing is
   written.
4. Readers go through the record: lmx_msg_now (exec.c) and lmx_msg_orphan_deadline (lm1/lm2). No other reader exists
   (grep of the three field names).
5. Reds, each a committed case: a setter from a worker's turn and from a child's turn returns INVALID with the value
   unchanged (lmx_msg_now and the deadline read back the old value); the setter from R0's turn (root_turn) and from
   main succeed; the three cells are found in R0's owned ranges and rooted; release_17 scenario 5 and orphan_mapped_17
   stay green unchanged.

QUESTIONS (each to be measured before it is claimed)
Q1. Where the cells live.
  (a) A new runtime unit, lmx_root_record.lm2, rooted in R0 beside R0's scheduler record: only R0 pays for it, and
      the scheduler record keeps its two-slot layout for every parent.
  (b) Extra slots in R0's lmx_sched_record: one record per Message, but the record's layout would differ between R0
      and every other parent, or every parent would carry three unused cells.
  Lean: (a).
Q2. When the record exists.
  (a) Created by runtime_new with R0 (bootstrap, R0's lane), so lmx_msg_now and the sweep never see "no record".
  (b) Lazily at the first setter call (as the scheduler record at the first step), with readers falling back to the
      defaults while absent: one fewer allocation for runtimes that never set a policy, one more branch per read.
  Lean: (a); to measure: runtime_new's allocation count moves by the record's allocations, and run_port_msg_path_storage
  pins pre-test allocations (3 today, 0c's 2c43c21f), so that pin moves with it.
Q3. The clock_test flag.
  (a) Keep it as a cell (set_now switches lmx_msg_now to the logical clock).
  (b) Delete it, with clock = 0 meaning "real clock": a value that also means "absent" (memory: one number, two
      meanings); a test may set_now(0).
  Lean: (a).
Q4. The authority of a setter from a turn on the host thread that is not R0's (today it passes on host_is_owner).
  (a) Refuse: R0's lane is R0's turn or the host outside any turn, nothing else.
  (b) Keep today's pass until (f).
  Lean: (a), which is 6f's (2); to measure: which callers, if any, set the clock from inside a non-R0 turn (0c's
  inventory lists all 16 set_now calls as main).

Liveness (measured):
- lmx_msg_liveness.lm1 is block liveness (ptr_in_block, block_has_range, block_is_live), no deadlines.
- The runtime has no liveness deadline cell. The threshold is an argument: lmx_msg_poll(rt, who, now, threshold, ...),
  lmx_msg_drive(rt, now, threshold), lmx_msg_live_check(rt, who, now, threshold).
- Per-Message liveness cells (lmx_message.h 182-187): live_wait_th, live_query_id, live_query_at, live_query_pend_id,
  live_query_pend_at, live_seq. Test seams writing them: lmx_msg_live_test_set_seq, lmx_msg_live_test_set_wait_th.
- lmx_msg_now readers: lm1 10, lm2 10, exec.c 2, the exec selftest 1, release_17 3.

So the runtime-level policy cells a host setter writes today are exactly two: rt->clock with rt->clock_test
(set_now), and rt->orphan_retain (set_orphan_retain). Everything else found is a per-Message cell (orphan_until,
live_*), written by its parent's lane or a test seam.

- lmx_msg_live_test_set_seq and lmx_msg_live_test_set_wait_th (lm1 2845, 2858): authority lmx_msg_require_owner(rt),
  per-Message cells (live_seq, live_wait_th); callers are lmx_message_selftest.lm1 784 and the exec selftest 3416
  and 3477, all from main before the child is mapped.

runtime_new (lm1 856-885), measured:
- calloc's the runtime, so clock = 0 and clock_test = 0 (lmx_msg_now reads the real clock until set_now);
- writes rt->next_addr = 1U (address allocation, not a policy cell) and rt->orphan_retain =

- attaches host and exec, creates R0 (address 1) and the UI lane (address 2), and sets the exec's UI lane.
