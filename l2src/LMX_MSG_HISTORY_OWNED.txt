L1 history-root bookkeeping extraction (2026-09-11)
==================================================

Matched ownership: Grok inbox/outbox 20260911-234500. This ports the existing
bdd6a62 lmx_message_exec.c prepare_failed_history/history_push/history_free/
commit_history_roots algorithm without changing policy. The Message, range and
root C structs remain the ABI; no locks, storage movement, graph mutation,
global registry, new role or physical result/throw carrier is introduced.

Public functions (lmx_msg_history_owned.h.lm1):
  lmx_msg_history_prepare(src,out) -> existing LMX_MSG status
  lmx_msg_history_commit(dst,head) -> void, consumes prepared list
  lmx_msg_history_dispose(head) -> void, consumes private list only

The caller supplies exclusive ownership, valid acyclic lists and a distinct
output slot that does not alias Message roots/next links. Dispose an earlier
prepared list before reusing the output slot. prepare resets out, privately
collects a classified ARRAY/CHILDREN graph and classified HISTORY roots,
deduplicates addresses and creates HISTORY-only nodes. RETAIN-only roots are
omitted. Existing behavior for unclassified/wrong-kind addresses is omission.
Failure frees the private prefix, leaves out null and changes neither owner.
The caller performs storage admission separately, then commits without further
allocation. Commit merges HISTORY into an existing destination node, preserving
its RETAIN bit, or inserts the private node; a null destination disposes it.
Neither commit nor dispose frees payloads. Caller still owns all lifecycle and
quiescence decisions. The helper does not make arbitrary output aliases safe.
