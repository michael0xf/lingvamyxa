## Scope implemented (per ticket 20260911-091600)
Numeric-arithmetic SYNTAX module only - no numerical evaluation, no
double/BigDecimal conversion. Produces a bounded postfix operation stream in
caller-provided storage.

- API: mixa_calc_syntax_parse(expr, expr_len, out, capacity, out_count, err_pos)
  -> int (MixaCalcSyntaxStatus).
- Op record struct MixaCalcOp { int kind; size_t offset; size_t length; },
  kind enum MixaCalcOpKind (NUMBER/ADD/SUB/MUL/DIV/POW/NEG).
- Number tokens retain exact source offset+length and the original lexeme is
  preserved verbatim in the caller's expression buffer (no atof/strtod).
- Grammar ported from ClearShell eval2() (ClearShell.java) with reference
  behaviour preserved: expression(+/-) -> term(*,/,^ at same precedence,
  plainly LEFT-associative) -> factor(unary +/-, parens, numbers). Reference
  permissive unclosed-paren behaviour (eat(')') result unchecked) is preserved
  and explicitly asserted by a test case.
- Statuses: OK/ERR_ARG/ERR_CAPACITY/ERR_SYNTAX/ERR_UNSUPPORTED. Capacity
  failure emits zero tokens beyond current count (by-design checked BEFORE each
  write, so storage is never partially overwritten).
- Unsupported constructs (letters/high bytes: variables, functions, degree
  postfix) return ERR_UNSUPPORTED with err_pos.
