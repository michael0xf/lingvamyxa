API: stack_init / stack_release / open(stack,rect,row,col,nrows,ncols,hb,
message) / dismiss / hit(stack,rect,cell_row,cell_col) / top / count. open()
is the single "missing-function action": it saves the covered parent cells,
draws translucent bg + single frame + centered literal message + one dismiss
button through the existing mixa_draw / mixa_button_panel components, and
pushes the top window's own button origin so hit() routes to the TOP window
only (mixa_button_panel_hit real path). dismiss() restores saved cells
verbatim, preserving the immediate parent and its state; stack grows
dynamically (no depth cap); text glyphs stay opaque with alpha on backgrounds
only. All code L1; no threads/locks/atomics, no replacement Message scheduler.
stack_release frees buffers without cell restore (documented, like
mixa_highlight_release).
