READ-ONLY: CLEARSHELL ENTER BEHAVIOR vs PROCESS_SEAM §2

ClearShell Implementation (clearshell_reference/com/mtk/shell/ClearShell.java):
- enter() → pressChar("\n") at line 6425
- pressChar(c) at 7321: replaces selection (start/end) with char, invalidates text
- getLine() at 7365: extracts WHOLE line (finds \n before/after cursor, returns trimmed)
- getSelectionStart/End: uses EditText cursors for current position

Behavior: Enter replaces SELECTED TEXT with newline. If no selection, acts as insertion. Selection-based, not cursor-to-end-of-line.

PROCESS_SEAM §2 (PROCESS_SEAM.txt line 20-23):
"pressing Enter takes the line from its START up to the CURSOR, sends it plus a newline to the OS..."

This is DIFFERENT: line-start-to-cursor + newline (not selection-based).
