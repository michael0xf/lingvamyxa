Hard ban: Valued aggregates (not primitives)
-------------------------------------------
**Forbidden:** Valued C for structures, arrays, and similar aggregates —
no C `.` member access on structs, no struct/array by-value as the normal
model. Ordinary `\` field-follow → `->` only.

**Allowed:** primitives (char, int, size_t, floats, …) may be valued —
pass/store/return by value is fine.

If aggregate code is written that needs `.` / struct-by-value, fix it
(pointers / address forms). Extravagant aggregate exceptions only via
explicit C door: `c.` or `C:`.
