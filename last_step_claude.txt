Что входит в S6-2 (по фразам Михаила, внесённым в спеку: раздел 2 и 19.29.7):
- удалены счётчик держателей (refs) и реестр слотов рантайма;
- почтовый сервис - это роль, сегодня её исполняет R0. У R0 свой список живых
  записей: пары "указатель записи + id", поиск двоичный, не перебором. Регистрация
  идёт письмом при создании, снятие - письмом при release. На неизвестный адрес
  сервис отвечает отказом со статусом;
- ссылка на сервис - поле LMX самого Message, приходит от родителя. Почтовое API
  общее для любого L3 Thread; по умолчанию заглушка делегирует своему сервису;
- адрес Message - индекс у родителя (поле index). getAddress собирает a.b.c.d
  проходом по родителям. При смене родителя (handoff и переподвешивание сироты
  под R0) индекс выдаёт новый родитель;
- отправка по строке адреса - второй вход API. Тело R0 сегодня отказывает
  (KIND_REJECTED, статус LMX_MSG_UNDELIVERABLE); цепочка почтальонов - позже;
- удалены модуль lmx_msg_path_storage и массивы path, path_n, path_cap;
- транспорт опустошает только дорожка R0: pump требует владельца (хост, на котором
  идут ходы R0); тесты делают раунд R0 явно.
