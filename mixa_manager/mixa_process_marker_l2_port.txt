mixa_process_marker -- port to clean L2 (ticket 20260913-115500)
====================================================================

Status: source and parity harness COMPLETE. mixa_process_marker.h.lm1/
mixa_process_marker.lm1 are UNTOUCHED and remain the sole implementation
and the parity oracle. Translation against the CURRENT main frontend
fails with an already-known compiler barrier ("unknown foreign type")
-- expected, not a defect.

This is the most struct-heavy module ported this segment: two function-
pointer typedefs (MixaProcessMarkerFaultFn, MixaProcessMarkerCollideFn),
a fault vtable struct embedding both plus a void* ctx, a trivial one-
field identity-generator struct, a THIRD function-pointer typedef for
the sink (MixaProcessMarkerOrdinaryFn), a sink struct, and an 11-field
scanner struct (including a const pointer to the fault vtable). All
were preserved exactly, no flattening.
