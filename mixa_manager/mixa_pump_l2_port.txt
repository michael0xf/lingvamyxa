Scope
-----
Clean-L2 port of mixa_pump: drains mixa_backend_poll into an inbox
FIFO, then yields events via next -- one turn boundary (BACKEND_SEAM
7.1). 4 public functions (open/release/drain/next) plus pending, 79-
line real body.

No dedicated ABI probe pair, and NO L1 header unit to predef at all
-------------------------------------------------------------------------
Unlike every prior module this segment, mixa_pump.h has no L1 .h.lm1
counterpart anywhere in this codebase -- it is real, plain, hand-
written C (the same shape as mixa_selection.h/mixa_event_fifo.h
before it). MixaPump's own fields (inbox, is_open) are dereferenced
via `\` in the real body with no L1-level struct: declaration for
MixaPump/MixaEventFifo anywhere, proven safe by the established
finding from ticket 20260913-151000 (mixa_app_controller): l1trans's
own `\` dereference operator emits a plain C `->` and defers ALL
structural resolution to gcc. The L2 header therefore predefs nothing
at all -- 0 distinct predef'd files, the smallest chain of any module
this whole session.
