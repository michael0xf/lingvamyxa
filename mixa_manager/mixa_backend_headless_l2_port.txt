mixa_backend_headless L2 port (share-and-backends ticket 20260913-192700,
module 6 of 6 -- the LAST module in the standing list)
==========================================================================

Scope
-----
Clean-L2 port of mixa_backend_headless: the concrete headless
MixaBackendVTable implementation (no window, no font) used throughout
this whole session's own harnesses -- open/present/poll/clipboard_get/
clipboard_set/glyph/close plus the headless-only mixa_headless_push_
event/mixa_headless_frame_at test helpers. 10 functions, 379-line real
body.

No dedicated ABI probe pair, and no L1 header unit to predef at all
-------------------------------------------------------------------------
Like mixa_backend.h before it, mixa_backend_headless.h has no .h.lm1
counterpart anywhere in this codebase -- real, plain, hand-written C.
MixaHeadless's own fields are dereferenced via `\` with no L1-level
struct: declaration, proven safe by the established "`\` defers to
gcc" finding.

Files (new)
-------------
- mixa_manager/mixa_backend_headless_l2.h.lm1
    L2 ABI header. `include:`s the real, plain mixa_backend_headless.h
    directly (which itself plain-includes the real mixa_backend.h and
    mixa_event_fifo.h) -- zero predef'd files.
- mixa_manager/mixa_backend_headless.lm2
    The real 379-line body copied unchanged; all 10 functions
    preserved verbatim.
- mixa_manager/tests/mixa_backend_headless_parity_harness.lm1
    Real L1-vs-L2 harness. No dedicated selftest exists for this
    module alone in the accepted codebase -- it is exercised
    indirectly through mixa_backend_table_selftest.lm1, mixa_pump_
    selftest.lm1, mixa_app_loop_selftest.lm1 and others (all already
    re-verified clean by run_mixa.ps1's own regression sweep,
    unaffected by this port since it touches no real file). This
    harness instead exercises the module's own real contract directly:
    open() validates every required metric field and refuses ODD cell
    dimensions (the even-cell rule the half-cell mouse conversion
    depends on) plus real overflow guards; a real present()/frame_at()
    pixel round trip proves the frame buffer is genuinely copied and
    readable, with a too-small byte count refused; poll() on an empty
    inbox reports NONE promptly, a pushed event is delivered in real
    FIFO order, and a real RESIZE event delivered through poll actually
    reallocates the frame buffer to the new geometry (proven by writing
    to the new frame via present() then reading it back via frame_at());
    a real clipboard set/get round trip including the real short-
    buffer-reports-required-length contract and the real unset-
    clipboard-reports-empty-string case; push_event's own real pixel-
    to-half-cell conversion for both MOUSE and MOUSE_WHEEL kinds; glyph
    () reports MISSING for every valid layer and refuses an invalid
    one; and the singleton table constructor returns the IDENTICAL
    pointer across repeated calls. 44 checks.
- mixa_manager/run_mixa_backend_headless_l2_parity.ps1
    Dedicated runner. mixa_backend_headless.lm1 predefs nothing, so
    both sides separately link the same real mixa_event_fifo object
    every other headless-backend-driven harness this segment needs.

Barrier (current main) -- CONFIRMED-MATCHING the bodyless-forward-
