Why this module needed no adaptation at all
------------------------------------------------
Every prior module in this segment needed at least one workaround:
byte-sized MixaCell fields (tiles onward), const-local-decl rewrites,
array-index-field-access-needs-pointer-intermediate, or opaque-struct
test doubles for externally-owned types. MixaPointer has none of these
pressures -- its own struct is 4 plain int/size_t fields, and it calls
no function outside itself. This makes it the cleanest possible
confirmation that the ONLY remaining barrier for straightforward,
self-contained low-level C logic is the already-tracked closed-type-
allowlist issue in the entry-signature/forward-declaration path, not
any deeper semantic gap.
