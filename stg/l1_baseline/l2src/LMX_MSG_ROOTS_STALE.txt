lmx_msg_roots_drop_stale(m) is the existing drop_stale_roots_locked C algorithm
from 01a245b expressed in L1. Caller supplies exclusive Message ownership and
valid acyclic root/range lists, with distinct malloc-compatible root nodes.
The helper does not acquire a lock or decide when storage may be transferred.

A node with null p or an address not classifying in m->ranges is unlinked and
freed. Any classifying address remains, independent of kind/type/role. This is
the existing policy, not the narrower HISTORY preparation predicate. Survivors
keep their order, pointer values and role bits. There is no allocation, payload
free, metadata free, storage move or new Message ABI. A null Message is harmless.
