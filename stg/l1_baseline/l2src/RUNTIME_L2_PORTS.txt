THE BOOTSTRAP QUESTION, stated once for all allocators (branch, value, chars,
array, array_ref): as library units they can never carry the ABI names,
because a unit's open path allocates through them. The redirect proves the L2
SOURCE, not the runtime's bootstrap. Model §20: "the translator builds the
initial graph of the first Message". The load-order answer that follows from
it is that the initial graph of a unit (its callable Structures, METHOD
records, the two root arrays) should be EMITTED as translation-time data,
not built at run time by the allocators it contains; then opening a unit
allocates nothing and the allocators can be real symbols. That is emitter
work on the lead's side, after Stage B; raised 2026-09-14.
