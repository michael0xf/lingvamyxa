Storage API (no policy, no Message flags, no scheduler)
  LmxMsgBlock:
    void *base
    size_t n
    unsigned class          /* type/range class; not a source flag */
    void (*dispose)(void *base, size_t n)  /* 0 means free(base) */
    LmxMsgBlock *next

  int lmx_msg_blocks_push(LmxMsgBlock **head, LmxMsgBlock *node)
      node is already allocated; list is nonmoving; node addresses stay valid

  int lmx_msg_blocks_move_all(LmxMsgBlock **dst, LmxMsgBlock **src)
      splice src onto dst; *src = 0; no allocation; internal pointers unchanged

  int lmx_msg_blocks_dispose_all(LmxMsgBlock **head)
      exactly-once dispose/free of each payload then the node; *head = 0
      empty head is a no-op

Who may call (Grok policy, in lmx_message*)

  lifecycle_authority, handoff-ready, native_users==0, running==0,
  and every direct child disposed. Grok now calls this API from
  those sites and slot_free. LmxAdopted is gone. Grok will not
  add a second arena module.
