LmP0IndentStack becomes a foreign pointer type (d6, draft on e6bb09e7, 2026-09-14)

SCOPE (6f's ruling (a), 2026-09-14)
Trigger: 5e's repro 23e2dbb7 (parser-l2 Stage e slice 3). `stack\columns[idx]: value` with `@: LmP0IndentStack stack`
fails l2trans "unsupported index". LmP0IndentStack keeps legacy codes (14 `@:`, 15 `const: @(`, return 13), a
hand-written field table and dedicated sizeof and lm_own_new_zero cases; (b), widening l2_index_head for 14/15, would
add a feature to a legacy code, which decision 12 forbids. So: LmP0IndentStack becomes a foreign pointer type, as
LmP0Document (Stage B, the comment at l2trans.lm1 ~9485) and LmP0Stack; its codes, field table entries and the sizeof
and new_zero cases go; its field reads and writes use the foreign path, spelled as written and checked by C.
Order: after the bracket fix (d6/l2trans-bracket e6bb09e7).

DESIGN
1. Delete A1-A4 and the two name exclusions at 9547: the type interns through l2_foreign_intern like any foreign
   pointer (formal, const formal, local slot, return), with l2_need_p0 set as LmP0Document's is.
2. Delete U1's columns/count/capacity entries and the rf = 2/3/4 emissions; `stack\columns` reads and writes take the
   foreign field path (out_fld 5), spelled as written.
3. Delete U2's 14/15 terms, U5, U6's 14/15 lines, U7.
4. Delete U3: `c.sizeof(c.LmP0IndentStack)` reaches the general foreign branch (11162-11171), which emits it as
   written.
5. Delete U4's IndentStack line; parser_indent_stack.lm2:57 is rewritten to the spelling parser_stack_stream_port
   already uses, `return: (cast: (@: LmP0IndentStack) lm_own_new_zero(c.sizeof(c.LmP0IndentStack)))`. See Q2.
6. The generated C signatures stay `LmP0IndentStack *` and `const LmP0IndentStack *`, so indent_stack_abi.c is
   unchanged; run_candidate_indent measures it.
