Lingvamyxa Duktape Integration Plan
==================================

Status

Working provisioning plan for vendoring Duktape into the Lingvamyxa
runtime and exposing it as an Message Thread "duk" receiver. Companion to
include_python.txt; same verify / stage / generate / manifest pattern,
no runtime download. This is the smallest realistic embed in the
catalog.

Goal

An ES5.1 JavaScript engine that ships as a single prepared source file.
For lightweight user scripting where footprint and build simplicity
matter more than language level. If ES2023 is needed, use
include_quickjs.txt instead.

Tier

Tier 2. One .c file plus two headers. Compile with the project
toolchain. Many independent heaps.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain. uv or curl
only to fetch the distributable once.


2. Vendor the source
--------------------

Source: the Duktape release "distributable" tarball (duktape.org). It
already contains the prepared amalgamation:

    src/duktape.c
    src/duktape.h
    src/duk_config.h

Pin the release sha256. Commit third_party/duktape.tar.xz or just the
three src/ files under third_party/duktape/ .


3. CMake integration
--------------------

    option(LINGVAMYXA_ENABLE_DUK "Build the duk receiver" OFF)

    if(LINGVAMYXA_ENABLE_DUK)
      add_library(lingvamyxa_duk STATIC
        ${CMAKE_SOURCE_DIR}/third_party/duktape/duktape.c)
      target_include_directories(lingvamyxa_duk PUBLIC
        ${CMAKE_SOURCE_DIR}/third_party/duktape)
      target_compile_definitions(lingvamyxa_duk PUBLIC LINGVAMYXA_DUK=1)
    endif()

duk_config.h may need a few #defines on exotic targets; the defaults
cover Linux/macOS/Windows on x64 and arm64.


4. The C shim (dukhost)  --  lm1/build/dukhost.lm1.c
--------------------------------------------------

    duk_context *ctx = duk_create_heap_default();
    duk_int_t rc = duk_peval_string(ctx, src);   # 0 = ok
    result at the stack top: duk_get_number / duk_get_string / ...
    duk_destroy_heap(ctx);

    One heap per interpreter; create many, one per Message Thread.

    Arrays:  duk_push_external_buffer + duk_config_buffer over the arena
    buffer, then wrap as a Uint8Array/Float64Array on the JS side --
    no copy. Or duk_push_buffer for an owned copy.

    Errors:  non-zero rc -> the value on top is an Error; read .stack
    (or .message) and return an LMX failure record; duk_pop.

    No GIL. One duk_context per Message Thread.


5. ABI descriptors and the Message Thread receiver
--------------------------------------

    lm2/dukhost_abi.lm2      predef + fn.external prototypes
    receiver "duk", selector "duk.eval" / "duk.call"


6. Packages
-----------

None. Vendor pure-ES5 .js files and load them with duk_peval_string in
dependency order, or implement a tiny require() shim over a vendored
folder.


7. What the tool does not do
----------------------------

    write the body of lm_dukhost_* (the external-buffer bridge, the
    error mapping).


Appendix. Provisioning utility sketch  --  lm2/provision_duktape.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative.

========================================================================
# lm2/provision_duktape.lm2 -- vendor Duktape, wire the duk receiver

include
constant
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: DUK_VER "2.7.0"
constant: DUK_URL "https://duktape.org/duktape-2.7.0.tar.xz"
constant: DUK_SHA "REPLACE_ME"

fn: lm_duk_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedDuk.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_duktape.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_DUK \"Build the duk receiver\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_DUK)\n"
    c.fprintf: f "  set(D \"${CMAKE_SOURCE_DIR}/third_party/duktape\")\n"
    c.fprintf: f "  add_library(lingvamyxa_duk STATIC ${D}/duktape.c)\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_duk PUBLIC ${D})\n"
    c.fprintf: f "  target_compile_definitions(lingvamyxa_duk PUBLIC LINGVAMYXA_DUK=1)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_duk_write_shim_stub () int
    FILE: f
    f: fopen("lm2/dukhost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_duktape.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_dukhost_new () @: void\n"
    c.fprintf: f "    fn: lm_dukhost_free (@: void ctx)\n"
    c.fprintf: f "    fn: lm_dukhost_eval (@: void ctx; @: char code; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char archive 2048

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_join_path(archive, c.sizeof(archive), "third_party", "duktape.tar.xz") != 0
            return: 1
        if: lm_fetch(DUK_URL, archive) != 0
            return: 1
        if: lm_verify_sha256(archive, DUK_SHA) != 0
            return: 1
        # keep only src/{duktape.c,duktape.h,duk_config.h} under third_party/duktape
        if: lm_extract_subdir(cmake, archive, "duktape-2.7.0/src", "third_party/duktape") != 0
            return: 1
        if: lm_duk_write_cmake() != 0
            return: 1
        if: lm_duk_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("third_party/duktape/PROVISION_MANIFEST.txt", "duktape", DUK_VER, DUK_SHA) != 0
            return: 1

        c.printf: "provision_duktape.lm0: done. build with -DLINGVAMYXA_ENABLE_DUK=ON\n"
    return: 0
end: external
========================================================================
