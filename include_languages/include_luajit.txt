Lingvamyxa LuaJIT Integration Plan
=================================

Status

Working provisioning plan for vendoring LuaJIT into the Lingvamyxa
runtime and exposing it as an L5-style "luajit" receiver (or as the
"lua" receiver's fast backend). Companion to include_python.txt; same
verify / stage / generate / manifest pattern, with a small extra build
step and no runtime download.

Goal

Lua 5.1 semantics plus a tracing JIT that is competitive with C for
numeric loops, plus a C FFI: Lua code can declare and call C functions
and touch C structs directly, with no binding layer. That FFI is the
main reason to pick LuaJIT over PUC Lua for a Lingvamyxa embed -- it is
a near-free bridge to the already-bundled C libraries.

Tier

Tier 2. Self-contained C plus a DynASM build step. Vendor into
third_party/luajit, build a static lib with the project toolchain.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain.

LuaJIT's own build runs a bootstrap (minilua, buildvm) as part of the
process; the project's C compiler covers it. Cross-compiling needs
HOST_CC set for the bootstrap plus the usual TARGET_* -- note this for
the arm64/x64 matrix.


2. Vendor the source
--------------------

Source: the LuaJIT repository, v2.1 branch (there is no recent tagged
release; pin a commit). Fetch a tarball of that commit and record its
sha256. Commit third_party/luajit.tar.gz or the unpacked tree.


3. CMake integration
--------------------

LuaJIT ships a Makefile, not CMake. Two options:

    wrap        add a custom target that runs `make` in the vendored
                tree with CC / HOST_CC / TARGET_SYS from the CMake
                toolchain, then import src/libluajit.a
    port        use one of the maintained CMake ports (a single
                CMakeLists.txt over src/*.c plus the generated
                lj_bcdef.h / lj_ffdef.h / lj_libdef.h / lj_recdef.h /
                lj_folddef.h / buildvm outputs)

    option(LINGVAMYXA_ENABLE_LUAJIT "Build the luajit receiver" OFF)
    if(LINGVAMYXA_ENABLE_LUAJIT)
      add_custom_target(build_luajit
        COMMAND make -C ${CMAKE_BINARY_DIR}/libs/luajit-src
                CC=${CMAKE_C_COMPILER} BUILDMODE=static)
      add_library(lingvamyxa_luajit STATIC IMPORTED GLOBAL)
      set_target_properties(lingvamyxa_luajit PROPERTIES
        IMPORTED_LOCATION ${CMAKE_BINARY_DIR}/libs/luajit-src/src/libluajit.a)
      add_dependencies(lingvamyxa_luajit build_luajit)
    endif()


4. The C shim (luajithost)  --  lm1/build/luajithost.lm1.c
-------------------------------------------------------

    lua_State *L = luaL_newstate();  luaL_openlibs(L);  luaJIT_setmode(...)
    The C API is Lua 5.1's plus lua_getfield etc.

    FFI bridge (the point): instead of pushing an LmArray as a table,
    hand Lua a pointer + length and let script do

        local ffi = require("ffi")
        local v = ffi.cast("double*", ptr)

    reading the arena buffer in place, no copy, JIT-compiled access.

    Errors: lua_pcall + debug.traceback as the message handler, same as
    the Lua plan.

    No GIL. One lua_State per L5 thread for lock-free isolation.


5. ABI descriptors and the L5 receiver
--------------------------------------

    lm2/luajithost_abi.lm2   predef + fn.external prototypes
    receiver "luajit" (or make it the "lua" receiver's backend chosen by
    LINGVAMYXA_LUA_IMPL=puc|jit), selectors "lua.eval" / "lua.call"


6. Packages
-----------

LuaRocks works against LuaJIT (uses the 5.1 tree). Vendor a --tree as in
include_lua.txt. Pure-Lua rocks and the LuaJIT FFI cover most needs.


7. What the tool does not do
----------------------------

    write the body of lm_luajithost_* (the FFI pointer handoff, the
    traceback handler);
    set up cross-compilation HOST_CC wiring for every target;
    choose the LuaRocks set.


Appendix. Provisioning utility sketch  --  lm2/provision_luajit.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative.

========================================================================
# lm2/provision_luajit.lm2 -- vendor LuaJIT, wire the luajit receiver

include
constant
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: LJ_COMMIT "v2.1"
constant: LJ_URL "https://github.com/LuaJIT/LuaJIT/archive/refs/heads/v2.1.tar.gz"
constant: LJ_SHA "REPLACE_ME"

fn: lm_lj_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedLuaJit.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_luajit.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_LUAJIT \"Build the luajit receiver\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_LUAJIT)\n"
    c.fprintf: f "  set(LM_LJ_DIR \"${CMAKE_BINARY_DIR}/libs/luajit-src\")\n"
    c.fprintf: f "  add_custom_target(build_luajit COMMAND make -C ${LM_LJ_DIR} CC=${CMAKE_C_COMPILER} BUILDMODE=static)\n"
    c.fprintf: f "  add_library(lingvamyxa_luajit STATIC IMPORTED GLOBAL)\n"
    c.fprintf: f "  set_target_properties(lingvamyxa_luajit PROPERTIES IMPORTED_LOCATION ${LM_LJ_DIR}/src/libluajit.a)\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_luajit INTERFACE ${LM_LJ_DIR}/src)\n"
    c.fprintf: f "  add_dependencies(lingvamyxa_luajit build_luajit)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_lj_write_shim_stub () int
    FILE: f
    f: fopen("lm2/luajithost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_luajit.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_luajithost_new () @: void\n"
    c.fprintf: f "    fn: lm_luajithost_free (@: void state)\n"
    c.fprintf: f "    fn: lm_luajithost_eval (@: void state; @: char code; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char archive 2048

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_join_path(archive, c.sizeof(archive), "third_party", "luajit.tar.gz") != 0
            return: 1
        if: lm_fetch(LJ_URL, archive) != 0
            return: 1
        if: lm_verify_sha256(archive, LJ_SHA) != 0
            return: 1
        if: lm_extract_strip1(cmake, archive, "build/libs/luajit-src") != 0
            return: 1
        if: lm_lj_write_cmake() != 0
            return: 1
        if: lm_lj_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("build/libs/luajit-src/PROVISION_MANIFEST.txt", "luajit", LJ_COMMIT, LJ_SHA) != 0
            return: 1

        c.printf: "provision_luajit.lm0: done. build with -DLINGVAMYXA_ENABLE_LUAJIT=ON\n"
    return: 0
end: external
========================================================================
