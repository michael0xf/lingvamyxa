Lingvamyxa QuickJS-ng Integration Plan
=====================================

Status

Working provisioning plan for vendoring QuickJS-ng into the Lingvamyxa
runtime and exposing it as an Message Thread "js" receiver. Companion to
include_python.txt; same verify / stage / generate / manifest pattern,
no runtime download.

Goal

A modern, small JavaScript engine (ES2023) for user scripting and for
running pure-JS npm packages that do not need Node APIs. Also the JS
host needed by include_python_pyodide.txt.

Tier

Tier 2. A few C files, builds with the project toolchain into a static
lib. Many independent runtimes.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain. uv or curl
only to fetch the release tarball once.


2. Vendor the source
--------------------

Source: the quickjs-ng project releases (the maintained fork of Bellard's
QuickJS). Pin a release tag and its sha256. Commit
third_party/quickjs.tar.gz or the unpacked tree.

Core translation units: quickjs.c, libregexp.c, libunicode.c, cutils.c,
and the bignum unit (libbf.c / xsum.c depending on the release);
optionally quickjs-libc.c for a std/os module. Headers: quickjs.h,
quickjs-libc.h.


3. CMake integration
--------------------

    option(LINGVAMYXA_ENABLE_JS "Build the js receiver" OFF)

    if(LINGVAMYXA_ENABLE_JS)
      set(D ${CMAKE_BINARY_DIR}/libs/quickjs-src)
      add_library(lingvamyxa_js STATIC
        ${D}/quickjs.c ${D}/libregexp.c ${D}/libunicode.c
        ${D}/cutils.c ${D}/libbf.c ${D}/quickjs-libc.c)
      target_include_directories(lingvamyxa_js PUBLIC ${D})
      target_compile_definitions(lingvamyxa_js PUBLIC LINGVAMYXA_JS=1
        CONFIG_VERSION="ng")
    endif()

QuickJS-ng also ships its own CMakeLists.txt; using it directly is fine.


4. The C shim (jshost)  --  lm1/build/jshost.lm1.c
------------------------------------------------

    JSRuntime *rt = JS_NewRuntime();
    JSContext *ctx = JS_NewContext(rt);
    js_std_add_helpers(ctx, 0, NULL);           # optional std/os
    JSValue r = JS_Eval(ctx, src, len, "<lm>", JS_EVAL_TYPE_GLOBAL);

    One JSRuntime per interpreter; JS_SetMemoryLimit / JS_SetMaxStackSize
    to bound it. Many runtimes; a runtime is single-threaded.

    Arrays:  JS_GetTypedArrayBuffer / JS_NewArrayBufferCopy for
    Lingvamyxa -> JS; JS_GetArrayBuffer on a returned ArrayBuffer for
    JS -> Lingvamyxa (borrow the pointer, keep the JSValue duped as the
    external-view destructor).

    Errors:  JS_IsException(r) -> JS_GetException(ctx), read .name /
    .message / .stack, format into an LMX failure record.

    Pending jobs (promises):  drain with JS_ExecutePendingJob in a loop
    after eval if the script uses async.

    No GIL. One JSRuntime per Message Thread.


5. ABI descriptors and the Message Thread receiver
--------------------------------------

    lm2/jshost_abi.lm2       predef + fn.external prototypes
    receiver "js", selector "js.eval" / "js.call"

    js.eval "import('mustache').then(m => m.render(tpl, view))"


6. Packages
-----------

No native addons. Bundle pure-JS packages: run a one-off bundler
(esbuild / rollup) at provision time to produce a single .js per entry
point, or vendor the package's dist/ files. A minimal CommonJS/ESM
loader over a vendored node_modules also works for simple trees.


7. What the tool does not do
----------------------------

    write the body of lm_jshost_* (the ArrayBuffer bridge, the job
    pump, the exception mapping);
    bundle or vet the JS package set.


Appendix. Provisioning utility sketch  --  lm2/provision_quickjs.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative.

========================================================================
# lm2/provision_quickjs.lm2 -- vendor QuickJS-ng, wire the js receiver

include
constant
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: QJS_VER "0.8.0"
constant: QJS_URL "https://github.com/quickjs-ng/quickjs/archive/refs/tags/v0.8.0.tar.gz"
constant: QJS_SHA "REPLACE_ME"

fn: lm_qjs_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedJs.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_quickjs.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_JS \"Build the js receiver\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_JS)\n"
    c.fprintf: f "  set(D \"${CMAKE_BINARY_DIR}/libs/quickjs-src\")\n"
    c.fprintf: f "  add_library(lingvamyxa_js STATIC ${D}/quickjs.c ${D}/libregexp.c ${D}/libunicode.c ${D}/cutils.c ${D}/libbf.c ${D}/quickjs-libc.c)\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_js PUBLIC ${D})\n"
    c.fprintf: f "  target_compile_definitions(lingvamyxa_js PUBLIC LINGVAMYXA_JS=1)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_qjs_write_shim_stub () int
    FILE: f
    f: fopen("lm2/jshost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_quickjs.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_jshost_new () @: void\n"
    c.fprintf: f "    fn: lm_jshost_free (@: void ctx)\n"
    c.fprintf: f "    fn: lm_jshost_eval (@: void ctx; @: char code; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char archive 2048

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_join_path(archive, c.sizeof(archive), "third_party", "quickjs.tar.gz") != 0
            return: 1
        if: lm_fetch(QJS_URL, archive) != 0
            return: 1
        if: lm_verify_sha256(archive, QJS_SHA) != 0
            return: 1
        if: lm_extract_strip1(cmake, archive, "build/libs/quickjs-src") != 0
            return: 1
        if: lm_qjs_write_cmake() != 0
            return: 1
        if: lm_qjs_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("build/libs/quickjs-src/PROVISION_MANIFEST.txt", "quickjs-ng", QJS_VER, QJS_SHA) != 0
            return: 1

        c.printf: "provision_quickjs.lm0: done. build with -DLINGVAMYXA_ENABLE_JS=ON\n"
    return: 0
end: external
========================================================================
