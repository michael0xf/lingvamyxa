Lingvamyxa Wren / s7 / Chibi-Scheme Integration Plan
===================================================

Status

Working provisioning plan for vendoring a small class- or Scheme-based
language -- Wren, s7 or Chibi-Scheme -- into the Lingvamyxa runtime and
exposing it as an Message Thread "wren" (or "scm") receiver. Companion to
include_python.txt; same verify / stage / generate / manifest pattern,
no runtime download.

Goal

A minimal scripting language with a clean C embedding API. Three options
in one plan:

    Wren    small class-based language with fibers; single amalgamation
            wren.c + wren.h; deterministic, no GC surprises for scripts.
    s7      a Scheme (R7RS-ish) in a single s7.c + s7.h; from the Common
            Music / Snd project; trivially embeddable, good C interop.
    Chibi   R7RS Scheme; small C core (libchibi-scheme) plus a Scheme
            module library directory to stage.

Tier

Tier 2. One or two C files (Wren, s7) or a small make (Chibi). Project
toolchain, static lib.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain. uv or curl to
fetch the release once. Wren's amalgamation is generated by a bundled
Python script; the release tarball ships it prebuilt.


2. Vendor the source
--------------------

    Wren   from wren.io / the git repo; take src/ + the generated
           wren.c amalgamation (util/generate_amalgamation.py output),
           or the release. Header: wren.h.
    s7     from the cm / s7 repository; a single s7.c + s7.h + s7.scm.
    Chibi  from the chibi-scheme repository; C sources plus lib/ (the
           R7RS module tree).

Pin the sha256. Commit third_party/wren/ (or /s7, /chibi).


3. CMake integration
--------------------

    option(LINGVAMYXA_ENABLE_WREN "Build the wren receiver" OFF)

    if(LINGVAMYXA_ENABLE_WREN)
      add_library(lingvamyxa_wren STATIC
        ${CMAKE_SOURCE_DIR}/third_party/wren/wren.c)
      target_include_directories(lingvamyxa_wren PUBLIC
        ${CMAKE_SOURCE_DIR}/third_party/wren)
      target_compile_definitions(lingvamyxa_wren PUBLIC LINGVAMYXA_WREN=1)
    endif()

s7: same shape with s7.c and -DWITH_C_LOADER as desired.
Chibi: add_subdirectory or a custom `make libchibi-scheme.a`, and stage
third_party/chibi/lib -> build/libs/chibi-lib, set the module path in
the shim.


4. The C shim
-------------

Wren  --  lm1/build/wrenhost.lm1.c

    WrenConfiguration cfg; wrenInitConfiguration(&cfg);
    cfg.writeFn / cfg.errorFn -> capture into an LMX failure record
    WrenVM *vm = wrenNewVM(&cfg);
    WrenInterpretResult r = wrenInterpret(vm, "lm", src);
    wrenFreeVM(vm);
    Values cross via wrenGetSlot* / wrenSetSlot*; a contiguous LmArray
    becomes a foreign class wrapping the arena pointer (no copy) or a
    List (copy).

s7  --  lm1/build/s7host.lm1.c

    s7_scheme *s7 = s7_init();
    s7_pointer v = s7_eval_c_string(s7, src);
    Errors via s7_error / an *error-hook*; s7 has native float-vectors
    (s7_make_float_vector) that can alias external memory.

Chibi  --  sexp ctx = sexp_make_eval_context(...);
    sexp_eval_string(ctx, src, -1, NULL); bytevectors for binary data.

No GIL in any; one VM/context per Message Thread.


5. ABI descriptors and the Message Thread receiver
--------------------------------------

    lm2/wrenhost_abi.lm2     predef + fn.external prototypes
    receiver "wren" (or "scm"), selector "<x>.eval" / "<x>.call"


6. Packages
-----------

Wren and s7: none; vendor source files. Chibi: vendor its lib/ tree and
any extra .sld modules.


7. What the tool does not do
----------------------------

    write the body of the chosen shim;
    stage Chibi's module library and wire its search path.


Appendix. Provisioning utility sketch  --  lm2/provision_wren.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative;
shows the Wren path.

========================================================================
# lm2/provision_wren.lm2 -- vendor Wren, wire the wren receiver

include
constant
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: WREN_VER "0.4.0"
constant: WREN_URL "https://github.com/wren-lang/wren/archive/refs/tags/0.4.0.tar.gz"
constant: WREN_SHA "REPLACE_ME"

fn: lm_wren_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedWren.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_wren.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_WREN \"Build the wren receiver\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_WREN)\n"
    c.fprintf: f "  set(D \"${CMAKE_SOURCE_DIR}/third_party/wren\")\n"
    c.fprintf: f "  add_library(lingvamyxa_wren STATIC ${D}/wren.c)\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_wren PUBLIC ${D})\n"
    c.fprintf: f "  target_compile_definitions(lingvamyxa_wren PUBLIC LINGVAMYXA_WREN=1)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_wren_write_shim_stub () int
    FILE: f
    f: fopen("lm2/wrenhost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_wren.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_wrenhost_new () @: void\n"
    c.fprintf: f "    fn: lm_wrenhost_free (@: void vm)\n"
    c.fprintf: f "    fn: lm_wrenhost_eval (@: void vm; @: char code; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char archive 2048

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_join_path(archive, c.sizeof(archive), "third_party", "wren.tar.gz") != 0
            return: 1
        if: lm_fetch(WREN_URL, archive) != 0
            return: 1
        if: lm_verify_sha256(archive, WREN_SHA) != 0
            return: 1
        if: lm_extract_strip1(cmake, archive, "third_party/wren") != 0
            return: 1
        # generate wren.c amalgamation if absent
        if: lm_wren_write_cmake() != 0
            return: 1
        if: lm_wren_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("third_party/wren/PROVISION_MANIFEST.txt", "wren", WREN_VER, WREN_SHA) != 0
            return: 1

        c.printf: "provision_wren.lm0: done. build with -DLINGVAMYXA_ENABLE_WREN=ON\n"
    return: 0
end: external
========================================================================
