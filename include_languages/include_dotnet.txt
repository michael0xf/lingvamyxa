Lingvamyxa .NET CoreCLR Integration Plan
=======================================

Status

Working provisioning plan for bundling the .NET runtime into the
Lingvamyxa runtime and exposing it as an L5-style "clr" receiver.
Companion to include_python.txt; same fetch / verify / stage / generate
/ populate / manifest pattern (Appendix B there).

Goal

Reach the whole NuGet ecosystem from Lingvamyxa without a system .NET:
C# and F# libraries -- Math.NET Numerics, ML.NET, ImageSharp,
NetTopologySuite (geometry), CsvHelper, and the rest.

Tier

Tier 1. Microsoft ships an official prebuilt relocatable runtime tarball
per RID, and nethost / hostfxr is a stable documented C hosting API that
ships inside it. Provisions like CPython.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain.

Add:

    uv or curl        fetch the runtime tarball
    tar               unpack

Optional: the .NET SDK (~200 MB) if you want `dotnet restore` for the
NuGet step; otherwise a small custom NuGet fetcher (below).


2. Fetch the redistributable
----------------------------

Source: the .NET release feed. Asset:

    dotnet-runtime-<ver>-<rid>.tar.gz     (dotnet-runtime-*.zip on Windows)

    rid   linux-x64 | linux-arm64 | osx-x64 | osx-arm64 | win-x64

Take the "runtime" pack (not "aspnetcore", not "sdk"). Also fetch the
matching host pack

    Microsoft.NETCore.App.Host.<rid>

for libnethost and the C headers, or take them from the runtime tree
under host/fxr and packs/. Pin each asset SHA-512 (the feed publishes
one) in the DISTS table of the tool.


3. Stage
--------

Unpack into build/libs/clr/ :

    build/libs/clr/shared/Microsoft.NETCore.App/<ver>/   the runtime
    build/libs/clr/host/fxr/<ver>/libhostfxr.*
    build/libs/clr/libnethost.*  +  nethost.h  hostfxr.h  coreclr_delegates.h

Managed assemblies you add go in build/libs/clr-asm/ .


4. CMake integration
--------------------

    option(LINGVAMYXA_ENABLE_CLR "Bundle .NET and build the clr receiver" OFF)

    if(LINGVAMYXA_ENABLE_CLR)
      set(LM_CLR_HOME ${CMAKE_BINARY_DIR}/libs/clr)
      add_library(lingvamyxa_clr INTERFACE)
      target_include_directories(lingvamyxa_clr INTERFACE ${LM_CLR_HOME}/include)
      target_link_libraries(lingvamyxa_clr INTERFACE ${LM_CLR_HOME}/libnethost.a)
      target_compile_definitions(lingvamyxa_clr INTERFACE LINGVAMYXA_CLR=1)
      install(DIRECTORY ${LM_CLR_HOME}/ DESTINATION bin/clr)
    endif()

libnethost is tiny and can be linked directly; hostfxr and the runtime
are loaded at runtime.


5. The C shim (clrhost)  --  lm1/build/clrhost.lm1.c
--------------------------------------------------

5.1 Start

    get_hostfxr_path(buf, &len, NULL)            # from libnethost
    load hostfxr, resolve hostfxr_initialize_for_runtime_config,
      hostfxr_get_runtime_delegate, hostfxr_close
    hostfxr_initialize_for_runtime_config("<app>.runtimeconfig.json", ...)
    hostfxr_get_runtime_delegate(ctx, hdt_load_assembly_and_get_function_pointer, &fn)

    The runtimeconfig.json (generated by the tool, section 7) points at
    the staged shared framework. One CoreCLR per process;
    AssemblyLoadContext gives isolation and unload.

5.2 Managed entry points

    C# side exposes static methods marked

        [UnmanagedCallersOnly]
        public static int Invoke(IntPtr argsBlob, int argsLen, out IntPtr result)

    load_assembly_and_get_function_pointer(asm_path, type_name,
      method_name, UNMANAGEDCALLERSONLY_METHOD, NULL, (void**)&invoke).

5.3 Value and array bridge, LmArray <-> .NET

    Lingvamyxa -> .NET: pass (pointer, length) and wrap on the managed
    side with new Span<T>(ptr, len) or
    System.Runtime.InteropServices.Marshal -- zero copy for blittable T.
    .NET -> Lingvamyxa: managed code returns a pinned pointer + length
    (GCHandle.Alloc(..., Pinned) or NativeMemory); the shim wraps it as
    an external-view LmArray whose destructor frees the handle.

5.4 Errors

    Managed Invoke catches, serialises Exception.ToString() into the
    result block with a fail flag; the shim turns it into an LMX failure
    record.

5.5 Stop

    hostfxr_close(ctx) at shutdown. CoreCLR itself is not torn down.


6. ABI descriptors and the L5 receiver
--------------------------------------

    lm2/clrhost_abi.lm2      predef + fn.external prototypes
    receiver "clr", selector "clr.call" -> lm_clrhost_call

    clr.load "MathNet.Numerics"
    clr.call "MathNet.Numerics.LinearAlgebra.Double.DenseMatrix" "OfArray" m


7. Packages
-----------

Two routes:

    with the SDK        dotnet restore against a .csproj / packages.lock.json,
                        then copy the resolved DLLs from ~/.nuget into
                        build/libs/clr-asm/
    without the SDK     fetch each .nupkg from
                        https://api.nuget.org/v3-flatcontainer/<id>/<ver>/<id>.<ver>.nupkg
                        (a .nupkg is a zip), extract lib/<tfm>/*.dll into
                        clr-asm/ ; ~50 lines, deterministic with a lock

Also generate app.runtimeconfig.json naming the staged framework version.


8. Packaging per platform
-------------------------

    Linux    build/libs/clr/ beside the binary; RPATH $ORIGIN/../libs/clr
    macOS    clr/ into Contents/Resources/clr; codesign every .dylib in
             the shared framework; @loader_path RPATH; the hardened
             runtime is generally fine for CoreCLR
    Windows  hostfxr.dll and coreclr.dll on the DLL search path


9. What the tool does not do
----------------------------

    write the body of lm_clrhost_* and the managed Invoke shim assembly
    (built once, shipped in clr-asm/);
    choose the NuGet set;
    NativeAOT anything (that needs the full SDK and a per-target compile
    and is a different model);
    codesign or notarise the macOS bundle.


Appendix. Provisioning utility sketch  --  lm2/provision_clr.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative.

========================================================================
# lm2/provision_clr.lm2 -- stage the .NET runtime, wire the clr receiver

include
os
constant
layout
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: CLR_VER "8.0.8"
constant: CLR_BASE "https://builds.dotnet.microsoft.com/dotnet/Runtime"

table:
    source
    name: CLRDIST
    columns: (class: class)  (@: char triple)   (@: char rid)     (@: char ext)     (@: char sha512)
    rows:
             linux_x64    "x86_64-unknown-linux-gnu"   "linux-x64"    "tar.gz"   "REPLACE_ME"
             linux_arm64  "aarch64-unknown-linux-gnu"  "linux-arm64"  "tar.gz"   "REPLACE_ME"
             mac_arm64    "aarch64-apple-darwin"       "osx-arm64"    "tar.gz"   "REPLACE_ME"
             mac_x64      "x86_64-apple-darwin"        "osx-x64"      "tar.gz"   "REPLACE_ME"
             win_x64      "x86_64-pc-windows-msvc"     "win-x64"      "zip"      "REPLACE_ME"
end: CLRDIST

fn: lm_clr_url (@: char buffer; size_t: size; @: char rid; @: char ext) int
    snprintf(buffer, size, "%s/%s/dotnet-runtime-%s-%s.%s", CLR_BASE, CLR_VER, CLR_VER, rid, ext)
return: 0

fn: lm_clr_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedClr.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_clr.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_CLR \"Bundle .NET\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_CLR)\n"
    c.fprintf: f "  set(LM_CLR_HOME \"${CMAKE_BINARY_DIR}/libs/clr\")\n"
    c.fprintf: f "  add_library(lingvamyxa_clr INTERFACE)\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_clr INTERFACE ${LM_CLR_HOME}/include)\n"
    c.fprintf: f "  target_link_libraries(lingvamyxa_clr INTERFACE ${LM_CLR_HOME}/libnethost.a)\n"
    c.fprintf: f "  target_compile_definitions(lingvamyxa_clr INTERFACE LINGVAMYXA_CLR=1)\n"
    c.fprintf: f "  install(DIRECTORY ${LM_CLR_HOME}/ DESTINATION bin/clr)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_clr_write_runtimeconfig () int
    FILE: f
    f: fopen("build/libs/clr/app.runtimeconfig.json", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "{ \"runtimeOptions\": { \"framework\": {\n"
    c.fprintf: f "  \"name\": \"Microsoft.NETCore.App\", \"version\": \"%s\" } } }\n" CLR_VER
    fclose(f)
return: 0

fn: lm_clr_write_shim_stub () int
    FILE: f
    f: fopen("lm2/clrhost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_clr.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_clrhost_start () int\n"
    c.fprintf: f "    fn: lm_clrhost_stop ()\n"
    c.fprintf: f "    fn: lm_clrhost_call (@: char asm; @: char type; @: char method; @: void argv; size_t: argc; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char url 1024
        c.array: []: char archive 2048
        @: char rid 0
        @: char ext 0
        @: char sha 0

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_clr_dist_lookup(lm_host_triple(), @ rid, @ ext, @ sha) != 0
            return: 1
        if: lm_clr_url(url, c.sizeof(url), rid, ext) != 0
            return: 1
        if: lm_join_path(archive, c.sizeof(archive), "third_party", "dotnet-runtime.tar.gz") != 0
            return: 1

        if: lm_fetch(url, archive) != 0
            return: 1
        if: lm_verify_sha512(archive, sha) != 0
            return: 1
        if: lm_extract_into(cmake, archive, "build/libs/clr") != 0
            return: 1
        if: lm_clr_write_cmake() != 0
            return: 1
        if: lm_clr_write_runtimeconfig() != 0
            return: 1
        if: lm_clr_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("build/libs/clr/PROVISION_MANIFEST.txt", "coreclr", CLR_VER, sha) != 0
            return: 1

        c.printf: "provision_clr.lm0: done. build with -DLINGVAMYXA_ENABLE_CLR=ON\n"
    return: 0
end: external
