Lingvamyxa Janet Integration Plan
================================

Status

Working provisioning plan for vendoring Janet into the Lingvamyxa
runtime and exposing it as an Message Thread "janet" receiver. Companion to
include_python.txt; same verify / stage / generate / manifest pattern,
no runtime download.

Goal

A modern Lisp designed for embedding: single amalgamated source, one
environment table per VM, immutable-by-default data, fibers for
lightweight concurrency, PEG grammars built in. Good for rules, DSLs and
data transforms authored by users.

Tier

Tier 2. One janet.c + janet.h from the release. Compile with the
project toolchain.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain. uv or curl to
fetch the release once.


2. Vendor the source
--------------------

Source: the janet-lang releases. Each release ships the amalgamation:

    janet.c        the whole interpreter
    janet.h        the embedding header
    janetconf.h    build-time config
    shell.c        optional standalone REPL (not needed for embedding)

Pin the release sha256. Commit third_party/janet/ .


3. CMake integration
--------------------

    option(LINGVAMYXA_ENABLE_JANET "Build the janet receiver" OFF)

    if(LINGVAMYXA_ENABLE_JANET)
      add_library(lingvamyxa_janet STATIC
        ${CMAKE_SOURCE_DIR}/third_party/janet/janet.c)
      target_include_directories(lingvamyxa_janet PUBLIC
        ${CMAKE_SOURCE_DIR}/third_party/janet)
      target_compile_definitions(lingvamyxa_janet PUBLIC LINGVAMYXA_JANET=1)
    endif()


4. The C shim (janethost)  --  lm1/build/janethost.lm1.c
------------------------------------------------------

    janet_init();
    JanetTable *env = janet_core_env(NULL);
    Janet out;
    int rc = janet_dostring(env, src, "<lm>", &out);   # 0 = ok
    ...
    janet_deinit();

    One VM per process by default (janet_init is global). For isolation
    across Message Threads use separate JanetTable environments and a lock,
    or build with JANET_THREADS and message between janet/thread
    abstractions.

    Arrays:  janet_wrap_buffer over a JanetBuffer aliasing the arena
    memory (no copy) or janet_wrap_tuple/array for a copy. Janet numbers
    are doubles; use its buffer/typed views for f64/i32 data.

    Errors:  rc != 0 -> `out` holds the error value / fiber; format the
    fiber stack (janet_stacktrace) into an LMX failure record.


5. ABI descriptors and the Message Thread receiver
--------------------------------------

    lm2/janethost_abi.lm2    predef + fn.external prototypes
    receiver "janet", selector "janet.eval" / "janet.call"


6. Packages
-----------

jpm is Janet's package manager; it needs Janet to run and installs into
a tree you can vendor (JANET_PATH). Most embeds vendor .janet files
directly.


7. What the tool does not do
----------------------------

    write the body of lm_janethost_* (the buffer bridge, the fiber
    stacktrace mapping);
    run jpm for a package set.


Appendix. Provisioning utility sketch  --  lm2/provision_janet.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative.

========================================================================
# lm2/provision_janet.lm2 -- vendor Janet, wire the janet receiver

include
constant
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: JANET_VER "1.36.0"
constant: JANET_URL "https://github.com/janet-lang/janet/releases/download/v1.36.0/janet-1.36.0.tar.gz"
constant: JANET_SHA "REPLACE_ME"

fn: lm_janet_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedJanet.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_janet.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_JANET \"Build the janet receiver\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_JANET)\n"
    c.fprintf: f "  set(D \"${CMAKE_SOURCE_DIR}/third_party/janet\")\n"
    c.fprintf: f "  add_library(lingvamyxa_janet STATIC ${D}/janet.c)\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_janet PUBLIC ${D})\n"
    c.fprintf: f "  target_compile_definitions(lingvamyxa_janet PUBLIC LINGVAMYXA_JANET=1)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_janet_write_shim_stub () int
    FILE: f
    f: fopen("lm2/janethost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_janet.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_janethost_start () int\n"
    c.fprintf: f "    fn: lm_janethost_stop ()\n"
    c.fprintf: f "    fn: lm_janethost_eval (@: char code; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char archive 2048

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_join_path(archive, c.sizeof(archive), "third_party", "janet.tar.gz") != 0
            return: 1
        if: lm_fetch(JANET_URL, archive) != 0
            return: 1
        if: lm_verify_sha256(archive, JANET_SHA) != 0
            return: 1
        if: lm_extract_strip1(cmake, archive, "third_party/janet") != 0
            return: 1
        if: lm_janet_write_cmake() != 0
            return: 1
        if: lm_janet_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("third_party/janet/PROVISION_MANIFEST.txt", "janet", JANET_VER, JANET_SHA) != 0
            return: 1

        c.printf: "provision_janet.lm0: done. build with -DLINGVAMYXA_ENABLE_JANET=ON\n"
    return: 0
end: external
