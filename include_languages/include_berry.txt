Lingvamyxa Berry / Umka / Gravity / Pocketlang / Pawn Integration Plan
====================================================================

Status

Working provisioning plan for vendoring one of the tiny embeddable
languages -- Berry, Umka, Gravity, Pocketlang or Pawn -- into the
Lingvamyxa runtime and exposing it as an L5-style receiver. Companion to
include_python.txt; same verify / stage / generate / manifest pattern,
no runtime download.

Goal

The lightest end of the catalog: each is a small self-contained C tree
with its own VM API, chosen by taste rather than ecosystem (all five
have tiny package stories). Pick one; the plan is the same shape.

    Berry        dynamically typed, class-based, used in Tasmota; small
                 flash/RAM budget. API: be_vm, be_loadstring, be_pcall.
    Umka         statically typed, compiles to bytecode; from the Tophat
                 engine. API: umkaAlloc/umkaInit/umkaCompile/umkaRun.
    Gravity      class-based, Swift-like syntax. API: gravity_vm_new,
                 gravity_compiler_run.
    Pocketlang   small, Python/Lua-flavoured. API: pkNewVM, pkInterpret.
    Pawn         C-like, compiles .p to .amx; the compiler is separate.
                 API: amx_Init / amx_Exec.

Tier

Tier 2. One small static lib from vendored C. Project toolchain.


1. Prerequisites (developer machine)
------------------------------------

Already in the project: CMake, Ninja, Git, a C toolchain. uv or curl to
fetch the chosen release once. (Pawn additionally needs its `pawncc`
compiler at build time to turn scripts into .amx, or ship pawncc as a
tool.)


2. Vendor the source
--------------------

Fetch the chosen project's release from its GitHub repo, pin the
sha256, commit under third_party/<lang>/ . All five build as a single
static library from a handful of .c files (Berry has a small amalgam
step via its `tools/`; Umka and Pocketlang ship CMake; Gravity ships a
Makefile/CMake).


3. CMake integration
--------------------

    option(LINGVAMYXA_ENABLE_BERRY "Build the berry receiver" OFF)

    if(LINGVAMYXA_ENABLE_BERRY)
      file(GLOB B_SRC ${CMAKE_SOURCE_DIR}/third_party/berry/src/*.c)
      add_library(lingvamyxa_berry STATIC ${B_SRC})
      target_include_directories(lingvamyxa_berry PUBLIC
        ${CMAKE_SOURCE_DIR}/third_party/berry/src)
      target_compile_definitions(lingvamyxa_berry PUBLIC LINGVAMYXA_BERRY=1)
    endif()

Umka / Pocketlang: add_subdirectory and link their exported target.


4. The C shim  --  lm1/build/<lang>host.lm1.c
-------------------------------------------

Berry:

    bvm *vm = be_vm_new();
    be_loadstring(vm, src);            // pushes a closure
    int rc = be_pcall(vm, 0);          // 0 = ok
    if (rc) { be_tostring(vm, -1) -> LMX failure record; }
    be_vm_delete(vm);

Umka:

    void *u = NULL; umkaAlloc(&u);
    umkaInit(u, "lm", src, 1<<20, NULL, 0, NULL, false, false, NULL);
    bool ok = umkaCompile(u) && umkaRun(u);
    if (!ok) { UmkaError e; umkaGetError(u, &e) -> LMX failure record; }
    umkaFree(u);

Arrays: each VM exposes a bytes/buffer or list type; wrap the arena
pointer with an accessor object for no-copy, or copy into a native
list. No GIL; one VM per L5 thread.


5. ABI descriptors and the L5 receiver
--------------------------------------

    lm2/<lang>host_abi.lm2   predef + fn.external prototypes
    receiver "<lang>", selector "<lang>.eval" / "<lang>.call"


6. Packages
-----------

None to speak of. Vendor script sources.


7. What the tool does not do
----------------------------

    write the body of the chosen shim;
    for Pawn, provide pawncc and the compile step.


Appendix. Provisioning utility sketch  --  lm2/provision_berry.lm2
==============================================================

Shared helpers mirror lm2/vcpkgFetch.lm2 and are elided. Illustrative;
shows the Berry path.

========================================================================
# lm2/provision_berry.lm2 -- vendor Berry, wire the berry receiver

include
constant
fn
prototype
unit

predef: "libc_abi.lm2"
predef: "lm2/own_abi.lm2"
include: "<stdio.h>" "<stdlib.h>" "<string.h>"

constant: BERRY_VER "1.2.0"
constant: BERRY_URL "https://github.com/berry-lang/berry/archive/refs/tags/v1.2.0.tar.gz"
constant: BERRY_SHA "REPLACE_ME"

fn: lm_berry_write_cmake () int
    FILE: f
    f: fopen("cmake/EmbeddedBerry.cmake", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_berry.lm0\n"
    c.fprintf: f "option(LINGVAMYXA_ENABLE_BERRY \"Build the berry receiver\" OFF)\n"
    c.fprintf: f "if(LINGVAMYXA_ENABLE_BERRY)\n"
    c.fprintf: f "  set(D \"${CMAKE_SOURCE_DIR}/third_party/berry\")\n"
    c.fprintf: f "  file(GLOB B_SRC ${D}/src/*.c)\n"
    c.fprintf: f "  add_library(lingvamyxa_berry STATIC ${B_SRC})\n"
    c.fprintf: f "  target_include_directories(lingvamyxa_berry PUBLIC ${D}/src ${D}/generate)\n"
    c.fprintf: f "  target_compile_definitions(lingvamyxa_berry PUBLIC LINGVAMYXA_BERRY=1)\n"
    c.fprintf: f "endif()\n"
    fclose(f)
return: 0

fn: lm_berry_write_shim_stub () int
    FILE: f
    f: fopen("lm2/berryhost_abi.lm2", "wb")
    if: f = 0
        return: 1
    c.fprintf: f "# generated by provision_berry.lm0\n"
    c.fprintf: f "predef: \"libc_abi.lm2\"\n\n"
    c.fprintf: f "external:\n"
    c.fprintf: f "    fn: lm_berryhost_new () @: void\n"
    c.fprintf: f "    fn: lm_berryhost_free (@: void vm)\n"
    c.fprintf: f "    fn: lm_berryhost_eval (@: void vm; @: char code; @: void result_out) int\n"
    c.fprintf: f "end: external\n"
    fclose(f)
return: 0

external:
    fn: main (int: argc; @@: char argv) int
        c.array: []: char cmake 1024
        c.array: []: char archive 2048

        if: lm_enter_project_root(argv[0]) != 0
            return: 1
        strcpy(cmake, lm_env_or_default("LM_CMAKE", "cmake"))

        if: lm_join_path(archive, c.sizeof(archive), "third_party", "berry.tar.gz") != 0
            return: 1
        if: lm_fetch(BERRY_URL, archive) != 0
            return: 1
        if: lm_verify_sha256(archive, BERRY_SHA) != 0
            return: 1
        if: lm_extract_strip1(cmake, archive, "third_party/berry") != 0
            return: 1
        # run third_party/berry/tools/coc if the generated headers are absent
        if: lm_berry_write_cmake() != 0
            return: 1
        if: lm_berry_write_shim_stub() != 0
            return: 1
        if: lm_write_manifest("third_party/berry/PROVISION_MANIFEST.txt", "berry", BERRY_VER, BERRY_SHA) != 0
            return: 1

        c.printf: "provision_berry.lm0: done. build with -DLINGVAMYXA_ENABLE_BERRY=ON\n"
    return: 0
end: external
